# Reto Especialista de Filtrado · Incomer

Evaluación interactiva (tipo juego) para técnicos nuevos de filtrado de Incomer.

- Pide nombre completo y cédula al inicio.
- 39 preguntas en 2 módulos: Operación de Filtrado (28) y Limpieza y Aseo (11).
- Se aprueba cada módulo con **más del 85 %**; si no, la persona repite el módulo y no se genera el diploma.
- Al aprobar ambos módulos genera un diploma descargable (PNG y PDF) con el logo de Incomer.
- Accesible: lectura en voz alta (Web Speech API), atajos de teclado, tamaño de letra y alto contraste.
- Las novedades se reportan al responsable de mantenimiento o al coordinador.

## Uso

Es un solo archivo estático (`index.html`), sin dependencias ni compilación; solo carga la fuente Poppins desde Google Fonts.

Abrir `index.html` en el navegador, o publicarlo con **GitHub Pages**:
`Settings → Pages → Deploy from a branch → main / (root)`.

La lectura en voz alta usa las voces en español instaladas en el dispositivo.
